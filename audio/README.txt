SAY THE NAME
============

Five to ten seconds of an elder saying a name, recorded as a voice memo
on a phone and saved as mp3. Ask each speaker first.

Upload a file with exactly one of these names and a small
"Say the name" button appears under that title on the page:

  bichom.mp3      Bichom             (Home)
  liocichla.mp3   the bird's name    (The bird)
  lichini.mp3     Lichini            (The Lichini walk)
  nettle.mp3      the nettle         (Nettle cloth)
  cave.mp3        the cave's name    (The cave)

More names (places, dishes) can be added: tell Claude which one.
